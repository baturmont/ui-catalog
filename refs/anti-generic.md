# Anti-generic defaults

Agents default to these when unconstrained. **Avoid** unless the brief or brand explicitly asks.

| Pattern | Why it reads AI-generic |
|---------|-------------------------|
| Purple → indigo gradients on white | Overused LLM landing default |
| Inter / Roboto / Arial only | No typographic character |
| Glassmorphism everywhere | Decorative noise; hurts industrial UIs |
| Soft gray cards + drop shadows on every block | “Dashboard by template” look |
| Pill chip clusters + stat strips in the hero | Clutter; multiple jobs in one viewport |
| Neon glow / dark cyber defaults | Trend cosplay |
| Stock “SaaS hero with 3 feature cards” | Same skeleton across unrelated products |

## Prefer instead

1. Catalog component with a clear source citation
2. Stack-appropriate kit (Shoelace vs shadcn vs Ionic)
3. Repo tokens when present
4. Distinct type + color from brand or a deliberate Open Props / Radix Colors palette — not purple-by-default
