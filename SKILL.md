# UI catalog (global)

Canonical checkout: this repository (or `/Users/Shared/Developer/cursor/ui-catalog/` on Tomoe Mac seats).

1. Read `WORKFLOW.md`
2. Use `INDEX.md` → `STACK-FILTERS.md` → `SOURCES.md` / `favorites/`
